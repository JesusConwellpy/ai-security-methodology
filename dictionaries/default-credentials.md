## Testing Methodology

### Common weak password patterns for Chinese enterprise:

```bash
# Numeric patterns
admin/123456
admin/12345678
admin/888888
admin/666666

# Vendor name patterns
admin/<vendorname>
admin/<vendorname>123
admin/<productname>
admin/Admin@123

# Seasonal patterns (common in Chinese orgs)
admin/2024
admin/202401
admin/Admin2024
admin/Password2024

# Combinations
admin/admin123
admin/admin@123
admin/Admin123!
admin/admin!@#123
```

### URL parameters frequently tested:

```bash
# During auth testing, check these parameters
username=admin&password=admin
username=admin&password=123456
username=admin%40admin.com&password=admin
administrator/administrator
```

### Default credential scan tools:

```bash
# Use with Hydra / Medusa for web forms
hydra -l admin -P default_passwords.txt target http-post-form "/login:user=^USER^&pass=^PASS^:F=incorrect"

# Use with CrackMapExec for SMB/WinRM
crackmapexec smb target -u users.txt -p passwords.txt
crackmapexec winrm target -u users.txt -p passwords.txt
```
