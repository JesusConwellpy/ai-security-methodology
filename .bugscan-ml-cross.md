## A. New Content in model-attacks/index.md (attribute inference, model reconstruction)

### A1. Attribute Inference (lines 776-846)

- **No duplication** with Membership Inference (section 6, line 518). MI determines *whether* a record was training data; attribute inference determines the *value* of an unknown attribute. These are distinct attacks with different goals and different mathematical formulations.
- **No duplication** with Model Inversion (section 2, line 100). Model inversion reconstructs *input features* from a target output; attribute inference infers a single protected-attribute value from prediction confidence. Correctly distinguished via doc text: "Unlike membership inference which determines whether a record was in training data, attribute inference reveals the *value* of an unknown attribute" (line 779).
- **Verification criteria present** (line 1014): "inferred attribute matches true attribute significantly better than random (>50% accuracy for binary attributes, >25% for 4-class)".
- **Pitfall noted** (line 1029-1031): "Fairness constraints vs attribute inference" and "Proxy feature correlation" correctly describe edge cases.

### A2. Model Reconstruction (lines 848-973)

- **No duplication** with Model Extraction (section 5, line 398). The doc explicitly distinguishes (line 851-852): "distinguishable from model extraction... because the goal is *exact weight recovery*." And again at line 973: "This is fundamentally different from model extraction."
- **Key theoretical boundary noted** (line 1031): "ReLU-only reconstruction" — correctly states the attack only works for ReLU-activated networks.
- **Key practical limitation noted** (line 1032-1033): "Pre-activation access required" and "Scalability bound."
- **Verification criteria present** (line 1015): "reconstructed weights produce identical outputs to the target model on random test inputs (MSE < 1e-6 or exact activation pattern match)."
